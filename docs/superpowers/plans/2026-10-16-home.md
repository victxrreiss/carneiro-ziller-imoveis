# Home Carneiro & Ziller — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home do handoff em Next.js 16, com paridade visual com o `Home.html` em 1440 e 390px, sem favoritos, sem "Anunciar imóvel" e sem a seção CTA "Proprietários".

**Architecture:** App Router com componentes de servidor por seção. Só são cliente as abas, a busca e o menu mobile. Tokens do README em `@theme` do Tailwind v4. Os dados vêm de uma camada `lib/imoveis` assíncrona sobre um mock tipado. A paridade é medida por Playwright + pixelmatch, seção a seção, contra o `Home.html` servido localmente.

**Tech Stack:** Next 16.4, React 19, TypeScript, Tailwind 4.3, Vitest 5 + Testing Library + jsdom, Playwright 1.64 + pixelmatch + pngjs + @axe-core/playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-home-design.md`

## Global Constraints

- Valores visuais copiados do `docs/handoff/home/Home.html`. O README só vale nas Lacunas.
- Cantos retos (`radius 0`) em tudo.
- O vinho `#78323D` só aparece nos pontos listados no README.
- Fontes self-hosted (`next/font/local`). Nada de Google Fonts.
- `prefers-reduced-motion: reduce` desliga as transições.
- Foco: `outline: 2px solid #0F1D24; outline-offset: 3px`.
- `line-height: normal` no `body`, como o UA do HTML de referência. O preflight do Tailwind usa 1.5 e quebraria a paridade.
- Commits só depois da conferência do usuário (fluxo do CLAUDE.md). Nenhuma task commita.

## Review Focus

1. Busca com `q` vazio ou com caracteres especiais (`&`, `#`, acentos): a URL tem que sair codificada, sem quebrar a query. É testado na Task 5.
2. Viewport entre 900 e 1100px: header e hero não podem gerar rolagem horizontal. É testado na Task 9 (varredura em 1024px).
3. Navegação só por teclado nas abas: setas, Home e End movem o foco e a seleção, e só a aba ativa fica no tab order. É testado na Task 4.
4. Menu mobile aberto e janela redimensionada para 900px ou mais: o menu tem que sumir sem deixar estado preso. É testado na Task 3 (o painel tem `min-[900px]:hidden`).
5. Imagens lazy ainda não carregadas na hora da captura: o teste de paridade rola a página e espera `img.complete` antes de capturar (Task 2).

```ts
export async function prepareReference(page: Page, width: number) {
  await page.evaluate((w) => {
    document.querySelectorAll('[data-fav]').forEach((el) => el.remove());
    document.querySelectorAll('header a').forEach((a) => { if (a.textContent?.trim() === 'ANUNCIAR IMÓVEL') a.remove(); });
    document.querySelector('section[aria-labelledby="cta-titulo"]')?.remove();
    document.querySelectorAll('footer nav a').forEach((a) => {
      const t = a.textContent?.trim();
      if (t === 'Anunciar imóvel' || t === 'Favoritos') a.remove();
    });
    const sel = document.querySelector<HTMLElement>('section[aria-labelledby="sel-titulo"]');
    if (sel) sel.style.paddingBottom = '120px';
    if (w < 600) document.querySelectorAll<HTMLElement>('.zc-tile').forEach((t) => (t.style.height = '280px'));
  }, width);
}
```
